Delivery Settings / ডেলিভারি

User checkout-এর location selector external maintained Bangladesh geo dataset ব্যবহার করবে। Division → District → Upazila/Thana → Union/Ward → Village auto cascade হবে।

1. Division / বিভাগ

8টি division auto list.

2. District / জেলা

Division select করলে শুধু সেই division-এর district আসবে।

3. Upazila/Thana / উপজেলা

District অনুযায়ী auto list.

4. Union/Ward / ইউনিয়ন

Upazila অনুযায়ী union/ward auto list.

5. Village / গ্রাম

Union select করলে available villages auto list হবে।

6. Extra Address / বাড়ির ঠিকানা

House, road, landmark, phone ইত্যাদি user নিজে দেবে।

Data note / ডেটা নোট

Current selector uses the public @olism/bd-geo dataset because it exposes divisions, districts, upazilas/thanas, unions/wards and villages with Bangla + English names. The dataset can change over time; for high-stakes address verification, cross-check authoritative sources.

Menus / মেনু

Main menu labels ও visibility control করুন। Category menu নিজে থেকে Categories collection থেকে তৈরি হবে।

Theme / Premium Colors
